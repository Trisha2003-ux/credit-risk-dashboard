# Credit Risk & Probability of Default Dashboard

An interactive Streamlit dashboard for analysing customer credit risk and probability of default.

## Features
- Model performance comparison
- ROC-AUC comparison
- Risk-band distribution
- Observed default rates
- Predicted probability of default
- Customer-level risk explorer

## Models
- XGBoost
- Random Forest
- Logistic Regression

## Tech Stack
Python | Pandas | Plotly | Streamlit
